# Lab-3-Bash-Scripting---Build-a-Reconnaissance-Tool
## Scenario
## Practical context
You have completed manual reconnaissance activities using several security tools. Your team now wants to reduce repetitive work by creating a simple command-line utility that allows an analyst to supply an authorized target and select the reconnaissance tool to run.

You have therefore been assigned to build a beginner Bash reconnaissance automation tool that accepts a target dynamically, presents a menu, validates basic input and executes WhatWeb, Nmap or DIRB according to the analyst's selection.

## Lab Objectives
This laboratory showcases how I was be able to create and execute a Bash script, using variables and user input, implementing conditional logic using if and case, check whether required commands are available, invoke reconnaissance tools from a script, avoid hardcoded targets, handle invalid input, make a script executable and explain how the completed automation works.
